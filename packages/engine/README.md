# Engine

文章を意味単位へ分け、RSVPの最終表示フレーム、読む速さ、現在位置を計算します。

## 入出力

`segmentText`は文字列を意味上の`ReaderUnit[]`へ分割します。各単位には、原文、文番号、種類、開始位置、終了位置が入ります。位置の単位はUTF-16コード単位です。

`buildRsvpFrames`は固定された書体の実測幅を入力に、必要な再分割と表示時間を確定した`RsvpFrame[]`を返します。code単位は再分割しません。Viewはフレームの文字列と固定書体をそのまま描画し、文字サイズや改行で再調整しません。

前後の文、現在の見出し、読書進捗、原文位置とフレームの対応もEngineが計算します。型と公開APIは`src/types.d.ts`にあります。

## 不変条件

- 原文の文字列と順序を保つ
- すべての意味単位と表示フレームに原文上の開始位置と終了位置を持たせる
- code以外の表示フレームは、入力された計測方法と最大幅に収まる
- 表示時間は最終表示フレームに対して一度だけ確定する
- 同じ入力とロケールから同じ結果を返す
