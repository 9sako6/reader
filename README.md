# Reader

SafariまたはChromeで表示している文章を、通常表示またはRSVPへ切り替えるReaderです。本文、URL、読書位置は保存しません。

## 開発

```sh
mise install
pnpm install --frozen-lockfile
mise run check
mise run test
```
